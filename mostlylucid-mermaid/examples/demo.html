Manual checks

  • Scroll: tap a diagram, then swipe or use the wheel. The page should scroll and the diagram should stay fixed. Enable Pan & Zoom explicitly; disable it and repeat. Test mouse, one finger and pinch.
  • Controls: zoom in/out, reset, slide the toolbar away and show it again. Try each preset, including global visibility and the first diagram only.
  • Fullscreen: Tab stays in the dialog. Close by button, Escape and backdrop; focus returns to the opener. Try closing immediately, then cleanup while open.
  • Exports: download PNG and SVG in both themes, from the page and fullscreen. Open the files separately and inspect text, connectors, markers and colours.
  • Lifecycle: toggle themes rapidly using the slow renderer. Insert both dynamic forms, remove them, reinitialise twice, then clean up and restore. The last selected theme should win.
  • Environment: resize to 390px, change OS theme, enable reduced motion, and print. Try every diagram type with both renderers. Different layouts are expected; missing labels or controls are failures.

The two site explainers have their own replay, filtering, fallback and embedding checks. Use the local ASP.NET article preview to validate the complete site rendering path.
