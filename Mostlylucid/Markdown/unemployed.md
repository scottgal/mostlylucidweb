# The Code LLM Problem

Code LLMs are enablers (for people like me they're accelerators causing explosive productivity) BUT they also enable *everyone* to sketch out an app to solve a business problem (POORLY...but *free*)...


## AN AVALANCHE OF VIBE CODED SHIT

There it is, that's the problem. I don't deny MY stuff is coded using Code LLMs ([my frameworks are SPECIFICALLY designed for this use](https://www.mostlylucid.net/blog/behavioural-inference-systems-blog)) but man is it hard to convince peiople that the one errant em-dash in tour Readme.md DOESN'T mean this was some piece of crap vibe coded in a weekend.
